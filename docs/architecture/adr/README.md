# ADR (Architecture Decision Records)

## Зачем
Этот каталог хранит историю архитектурных решений:
- что было раньше;
- что изменили;
- почему приняли именно это решение;
- какие риски и как откатиться.

## Когда добавлять ADR
Добавляй ADR, если:
1. меняется архитектурный контракт;
2. меняются правила ранжирования/фильтрации/скоринга;
3. меняется компромисс “качество vs скорость vs поддержка”.

## Как именовать файл
`ADR-YYYYMMDD-XX-kebab-case.md`

Пример:
`ADR-20260223-01-model-rerank-fit-intent-split.md`
