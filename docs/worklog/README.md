# Worklog (Codex + User)

Этот каталог хранит рабочий журнал в формате Markdown:
- что обсуждали;
- какие решения приняли;
- какие команды запускались;
- какие файлы менялись;
- какие тесты и с каким результатом.

## Зачем это нужно

- Можно спокойно перечитать всю логику решений позже.
- Можно быстро восстановить контекст после перерыва.
- Удобно для onboarding нового члена команды.

## Формат файлов

Рекомендуемый формат имени:
- `YYYY-MM-DD-session-<short-topic>.md`

Пример:
- `2026-02-19-session-phase1-matching.md`

## Важно

- Это журнал внутри репозитория, он не заменяет историю чата в интерфейсе.
- Секреты (`MONGODB_URI`, API keys и т.п.) в журнал не записываются.
