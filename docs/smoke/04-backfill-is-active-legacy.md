# Smoke Test 04: One-off Backfill `is_active` (Legacy)

## Что тестируем

Проверяем корректность логики one-off миграции `tools/backfill_is_active_flag.py`:
- фильтр выбирает только документы без поля `is_active`.

## Набор данных

Unit-набор из `tests/test_import_tools.py`:
- без реальной Mongo;
- проверяется служебная функция фильтра.

## Этапы

1. Вызов `_legacy_active_filter()`.
2. Сравнение с ожидаемым Mongo-фильтром.

## Что проверяется

1. Миграция нацелена только на legacy-документы (`$exists: False`).
2. Нет риска массового изменения уже нормализованных документов.

## Что запускается

```bash
.venv/bin/pytest -q tests/test_import_tools.py -k "backfill_is_active"
```

## Ожидаемый результат

- Тест проходит.
- Фильтр миграции соответствует контракту.

## Возможные проблемы и ограничения

1. Тест не выполняет реальный `bulk_write`.
2. Реальный результат миграции зависит от данных в продовой БД.
