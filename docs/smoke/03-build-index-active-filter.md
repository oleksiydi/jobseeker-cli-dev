# Smoke Test 03: Build Index (Strict Active Filter)

## Что тестируем

Проверяем, что индексатор `build_job_index` использует строгий фильтр активности (`is_active == True`).

## Набор данных

Минимальный unit-набор из `tests/test_build_job_index.py`:
- проверка helper-функции фильтра активности;
- без реального Qdrant/Mongo.

## Этапы

1. Вызов helper-функции фильтра.
2. Сравнение фактического фильтра с ожидаемым контрактом.

## Что проверяется

1. Фильтр строго равен `{"is_active": True}`.
2. Контракт индексации не откатывается в совместимый режим.

## Что запускается

```bash
.venv/bin/pytest -q tests/test_build_job_index.py -k "active_vacancy_filter"
```

## Ожидаемый результат

- Тест проходит.
- Фильтр активности соответствует строгой политике.

## Возможные проблемы и ограничения

1. Покрывается только логика фильтра, не полный runtime индексатора.
2. Не выполняются операции embeddings/Qdrant.
