# Задача для Codex: POC CLI city → PLZ для Германии

## Цель

Сделать простой POC-скрипт на Python, который через CLI принимает название города Германии и возвращает список PLZ — почтовых индексов.

Важно: правильно писать **PLZ**, не PLC.

Пример:

```bash
python poc/plz_lookup.py --city "München"
```

Ожидаемый результат:

```text
PLZ for München:
80331
80333
80335
...
```

## Где разместить файл

Создать отдельную папку:

```text
poc/
```

И положить скрипт туда:

```text
poc/plz_lookup.py
```

Не добавлять этот POC в основную архитектуру проекта. Это отдельный экспериментальный скрипт.

## Зависимости

Использовать библиотеку:

```text
pgeocode
```

Также можно использовать:

```text
pandas
```

Если в проекте есть `requirements.txt`, добавить туда:

```text
pgeocode
pandas
```

Если в проекте используется `pyproject.toml`, добавить зависимости туда, не ломая существующую структуру.

## Что должен делать скрипт

Скрипт должен:

1. Принимать название города через CLI.
2. По умолчанию работать для Германии: `country = "de"`.
3. Через `pgeocode` находить PLZ, связанные с этим городом.
4. Автоматически использовать/скачивать базу `pgeocode`, если она ещё не загружена.
5. Убирать дубли PLZ.
6. Сортировать PLZ.
7. Выводить результат в обычном текстовом виде.
8. Поддерживать JSON-вывод через флаг `--json`.
9. Возвращать exit code `1`, если город не найден или параметр пустой.
10. Не добавлять MongoDB, API вакансий, конфиги, DI, классы, сложную архитектуру и тестовый фреймворк.

## CLI-параметры

Скрипт должен поддерживать:

```text
--city "München"   обязательный параметр
--country de       опционально, по умолчанию de
--limit 200        опционально, сколько результатов брать из pgeocode
--json             опционально, вывести результат в JSON
```
